Demo of document-ocr-engine, an OCR engine I wrote and trained from scratch. Pick an example receipt or upload a photo of a document. It finds every word, reads it and flattens the page.

Everything runs in your browser with ONNX Runtime Web, so your photo is never uploaded anywhere.

Code: https://github.com/adwitiyashukla/document-ocr-engine

The example receipts come from the CORD v2 test set (CC BY 4.0). The fonts are Atkinson Hyperlegible Next and Mono, under the SIL Open Font License (see fonts/OFL.txt).
